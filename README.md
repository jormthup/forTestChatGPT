# กาแฟจอมทัพ POS

เว็บ POS ภาษาไทย สกุลเงินบาท สำหรับแท็บเล็ต ใช้ Node.js 20+ โดยไม่ต้องติดตั้ง dependencies

```sh
npm start
npm test
```

เซิร์ฟเวอร์ฟังพอร์ต 3000 (เปลี่ยนด้วยตัวแปร `PORT`) เปิดเว็บผ่านที่อยู่เครื่องที่เข้าถึงได้จากแท็บเล็ต

## ความสามารถ

- เมนูแยกหมวด ค้นหา ร้อน/เย็น/ปั่น ความหวาน นมโอ๊ต หมายเหตุ จำนวน และส่วนลด
- รับเงินสด คำนวณเงินทอน หรือบันทึกโอนเงิน/พร้อมเพย์ พร้อมรูป QR ร้านที่อัปโหลดในหน้าตั้งค่า พนักงานต้องตรวจเงินเข้าก่อนยืนยัน ไม่มีการติดต่อธนาคาร
- พัก/เรียกบิล ใบเสร็จและพิมพ์ผ่านเบราว์เซอร์ ยกเลิกบิลพร้อมเหตุผลและคืนสต็อก
- เพิ่ม/แก้ไขเมนู ราคา สต็อกหน่วยขาย และแจ้งรายการใกล้หมด
- รายงานวันนี้ตามเวลาไทย เมนูขายดี ช่องทางรับเงิน รายจ่าย เปิด/ปิดกะและส่วนต่างเงินสด
- ตั้งค่าร้านและ VAT แบบบวกเพิ่ม ส่งออก CSV สำรองและกู้คืน JSON

## ขอบเขตการใช้งาน

รุ่นต้นแบบสำหรับอุปกรณ์เดียว: ข้อมูลอยู่ใน localStorage ของ browser แต่ละเครื่อง/แต่ละ origin ไม่ซิงก์ข้ามอุปกรณ์ ควรเปิดเพียงแท็บเดียวและสำรอง JSON ทุกวัน การล้างข้อมูล browser จะลบข้อมูลร้าน ไม่มี login หรือการจำกัดสิทธิ์ จึงควรใช้บนเครื่องที่ร้านควบคุมเท่านั้น

ยังไม่มีสต็อกวัตถุดิบตามสูตร ระบบสมาชิก loyalty การคืนเงินบางส่วน การรับชำระอัตโนมัติ หรือการเชื่อมเครื่องพิมพ์โดยตรง ใบเสร็จไม่ใช่ใบกำกับภาษีเต็มรูปแบบ รายจ่ายที่บันทึกถือเป็นเงินออกจากลิ้นชัก กะที่ปิดบันทึกในข้อมูลสำรอง

ก่อนใช้งานจริงหลายเครื่องต้องเพิ่ม backend/database สิทธิ์พนักงาน การสำรองส่วนกลาง และทดสอบกับอุปกรณ์ร้านจริง
