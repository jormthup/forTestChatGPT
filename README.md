# กาแฟจอมทัพ POS — เวอร์ชันทดลอง 2

**v0.2.0 · จัดเมนูเอง · รายงานชัดขึ้น**

เว็บ POS ภาษาไทย สกุลเงินบาท สำหรับแท็บเล็ตเครื่องเดียว ใช้ได้ทั้ง GitHub Pages (static) และ Node.js 20+ สำหรับพัฒนา ยังไม่มีระบบล็อกอินหรือฐานข้อมูลกลาง

## ทดลองใช้งาน

GitHub Pages: https://jormthup.github.io/forTestChatGPT/

ตั้งค่า repository ที่ Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save รอ deployment สำเร็จ (การ push ไม่ยืนยันว่า deploy สำเร็จ) ห้ามใช้โหมดไม่ระบุตัวตนหากต้องการเก็บข้อมูล

รันในเครื่อง:

```sh
npm start
```

เปิดพอร์ต 3000 หรือกำหนด `PORT` ไม่มี dependencies สำหรับการรันเว็บ dependencies ใน package.json ใช้สำหรับทดสอบ browser เท่านั้น

## เริ่มใช้งานร้าน

1. เปิด **ตั้งค่าร้าน** เพิ่มชื่อ โลโก้ ที่อยู่ โทรศัพท์ ข้อความท้ายใบเสร็จ ราคาตัวเลือก และ QR / ข้อมูลบัญชี แล้วบันทึก
2. เปิด **จัดการเมนู → เพิ่มเมนู** ใส่ชื่อ ราคา รายละเอียด ประเภทเครื่องดื่ม/อาหาร หมวดหมู่ และอัปโหลดรูป หมวดใหม่จะกลายเป็นแท็กบนหน้าขายทันที
3. เลือกเมนูเพื่อเพิ่มครั้งละ 1 รายการ ปรับจำนวนที่ตะกร้า ไม่มีสต็อกและไม่มีข้อจำกัดจำนวนตามสต็อก
4. รับเงินสดพร้อมเงินทอน หรือบันทึกโอน พนักงานต้องตรวจเงินเข้าเอง QR ไม่ได้ฝังยอดเงินอัตโนมัติ
5. เปิดรายงาน เลือกวันนี้/7 วัน/เดือนนี้/ช่วงเอง ดูเมนูขายดี ชั่วโมงขายดี ช่องทางรับเงิน รายจ่ายและประวัติกะ ส่งออก CSV ตามส่วนที่ต้องการ
6. สำรอง JSON ทุกวันและเก็บไว้นอกแท็บเล็ต CSV ใช้รายงาน ไม่ใช่ไฟล์กู้คืน

เครื่องใหม่เริ่มด้วยเมนูว่าง เมนูและบิลจากรุ่นก่อนยังอยู่ให้แก้หรือซ่อนเอง ไม่ลบเมนูเก่าหรือบิลโดยอัตโนมัติ ข้อมูลสต็อกและ emoji ของสินค้าเลิกใช้แล้ว รูปที่ไม่ได้อัปโหลดจะแสดง placeholder

## ความหมายของรายงาน

- นับตามวันที่ขายในเวลาไทย ยกเลิกบิลแล้วจะหักออกจากช่วงวันที่ขายเดิม ไม่ใช่วันที่กดยกเลิก
- ยอดก่อนส่วนลด − ส่วนลด = ยอดขายสุทธิไม่รวม VAT; บวก VAT = รับชำระรวม
- เฉลี่ยต่อบิล = รับชำระรวม / จำนวนบิลสำเร็จ
- รายเมนู/หมวดแสดงยอดหลังปันส่วนส่วนลดตามสัดส่วนราคา รวมราคาตัวเลือก ไม่รวม VAT
- บิลเก่าที่ไม่บันทึกหมวดไว้แสดง “ไม่ระบุ (บิลเก่า)” ไม่เดาหมวดจากเมนูปัจจุบัน
- เปรียบเทียบกับช่วงก่อนหน้าที่มีจำนวนวันเท่ากัน ถ้าไม่มีฐานเดิมจะไม่แสดงเปอร์เซ็นต์
- รับชำระหักรายจ่ายไม่ใช่กำไร ยังไม่หักต้นทุนสินค้า รายจ่ายนับเป็นเงินออกจากลิ้นชัก
- ประวัติกะกรองตามวันที่ปิดกะ ช่วงรายงานเลือกได้สูงสุด 366 วันต่อครั้ง

## รูปและข้อมูลร้าน

อัปโหลด PNG/JPEG/WebP ไม่เกิน 8 MB ระบบย่อรูปสินค้าเหลือด้านยาวไม่เกิน 640px โลโก้ 320px และ QR 1000px (PNG เพื่อรักษาความคมชัด) รูปบันทึกเฉพาะ browser และรวมใน JSON backup ไม่อัปขึ้น GitHub และไม่แชร์ไปเครื่องอื่น ต้องตรวจว่า QR ของร้านสแกนอ่านได้จริงหลังอัปโหลด

เมื่อพื้นที่เต็ม ระบบไม่ยืนยันการบันทึกและคงข้อมูลเดิมไว้ ให้สำรองข้อมูลและลดขนาด/จำนวนรูป ไม่ล้างข้อมูลเว็บไซต์เพื่อแก้ปัญหา

## ทดสอบ

```sh
npm ci
npm test
npx playwright install chromium
npm run test:e2e
```

Linux ที่มี Chromium อยู่แล้ว: `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e` ชุด browser ใช้ profile ชั่วคราวแยกจากข้อมูลร้าน

## ข้อจำกัด

ไม่มีระบบพนักงาน/สิทธิ์แอดมิน ทุกคนที่ใช้เครื่องนี้เปิดหน้าจัดการร้านได้ ข้อมูลอยู่ใน localStorage ต่อ browser/origin ไม่ซิงก์หลายเครื่อง ใช้แท็บเดียวเพื่อหลีกเลี่ยงข้อมูลเขียนทับกัน การเปลี่ยน URL/โดเมนต้องสำรองและกู้คืนข้อมูลเอง การเพิ่มไอคอนบนหน้าจอไม่ใช่การรับรองการทำงานออฟไลน์

ไม่มีสต็อก วัตถุดิบ ต้นทุน/กำไรสุทธิ ระบบสมาชิก การคืนเงินบางส่วน การรับชำระอัตโนมัติ หรือเชื่อมเครื่องพิมพ์โดยตรง ใบเสร็จไม่ใช่ใบกำกับภาษีเต็มรูปแบบ
