# v0.2.0 — จัดเมนูเอง · รายงานชัดขึ้น

Branch: `feature/admin-menu-reports-v0.2.0` → merge แบบ `--no-ff` เข้า `main` → annotated tag `v0.2.0` หลังตรวจผ่าน

## 1. เอาสต็อกออก

เอาป้ายคงเหลือ สถานะหมด ฟอร์มจำนวนสต็อก การจำกัดการขายตามสต็อก การตัด/คืนสต็อกและส่วนสต็อกใกล้หมดออก จำนวนที่ตะกร้าและบิลยังมีเพื่อขายหลายแก้ว ป๊อปอัปเลือกเมนูไม่มีฟิลด์จำนวน เพิ่มครั้งละ 1 แล้วปรับที่ตะกร้า

## 2. เมนูมาจากผู้จัดการร้าน

ร้านที่ใช้ใหม่ไม่มีสินค้าตัวอย่าง ผู้จัดการเพิ่มทีละรายการพร้อมชื่อ รายละเอียด ราคา รูป หมวดและประเภทสินค้า อัปโหลดดู preview เปลี่ยนรูปหรือลบรูปได้ รูปว่างแสดง placeholder แทน emoji สินค้าเดิมไม่ถูกลบทิ้ง ผู้จัดการแก้หรือซ่อนเอง การซ่อนเอาออกจากหน้าขายและแท็ก แต่ไม่แตะประวัติบิล

## 3. หมวดหมู่/แท็ก

ฟอร์มเสนอหมวดเดิมหรือพิมพ์หมวดใหม่ได้ หมวดใหม่ของเมนูที่เปิดขายจะปรากฏด้านบนทันที หนึ่งเมนูอยู่หนึ่งหมวด ชื่อ “ทั้งหมด” สงวนไว้สำหรับแท็กดูทั้งหมด ประเภทอาหาร/เครื่องดื่มแยกจากหมวด จึงสร้างหมวดใหม่ได้โดยไม่ทำให้ตัวเลือกเครื่องดื่มหาย

## 4. รายงานที่ใช้ตัดสินใจได้

- เลือกวันนี้ 7 วันล่าสุด เดือนนี้ และช่วงเอง พร้อมวันที่ไทยชัดเจน
- เปรียบเทียบรับชำระกับช่วงก่อนหน้าที่มีจำนวนวันเท่ากัน ไม่มีฐานเดิมไม่แสดงเปอร์เซ็นต์ชวนเข้าใจผิด
- แยกยอดก่อนส่วนลด ส่วนลด สุทธิไม่รวม VAT ภาษี รับชำระ จำนวนบิล จำนวนขาย และเฉลี่ยต่อบิล
- แนวโน้มรับชำระรายวัน เมนูขายดีพร้อมจำนวนและยอดสุทธิ หมวดสินค้า ช่องทางรับเงิน ชั่วโมงขายดีช่วยเตรียมร้าน/พนักงาน
- ดูรายจ่ายและประวัติกะที่ปิดพร้อมส่วนต่างเงินสด
- บิลยกเลิกแยกจำนวน/ยอดและไม่นับเป็นยอดขาย
- ส่งออก CSV สรุป รายเมนู รายวัน และรายชั่วโมง เปิดต่อใน spreadsheet ได้ ป้องกันข้อความชื่อสินค้าถูกตีความเป็นสูตร
- ยอดรายเมนูปันส่วนส่วนลดถึงระดับสตางค์ บิลใหม่เก็บหมวดขณะขาย บิลเก่าที่ไม่มีข้อมูลไม่เดาหมวดจากรายการปัจจุบัน

## 5. ตั้งค่าร้าน

เพิ่ม/เปลี่ยน/ลบโลโก้ พร้อม preview แสดงใน sidebar และใบเสร็จ เพิ่มโทรศัพท์ ข้อความท้ายใบเสร็จ ข้อมูลบัญชีรับโอน ปรับราคาปั่น/นมโอ๊ตได้ แสดง QR และบัญชีเมื่อเลือกโอน มีตัวอย่างหัว/ท้ายใบเสร็จก่อนบันทึก บิลใหม่เก็บชื่อ ที่อยู่ โทรศัพท์ และข้อความท้าย ณ วันที่ขาย โลโก้ใช้ปัจจุบันเพื่อไม่เก็บรูปซ้ำทุกบิล

## 6. ข้อมูลเก่าและการสำรอง

คง storage key เดิมเพื่อรักษาบิล เมนู บิลพัก รายจ่าย กะและชื่อร้าน ไม่ลบเมนูตัวอย่างเก่าที่ผู้ใช้อาจแก้แล้ว แปลงข้อมูลเป็น schemaVersion 2 และเลิกใช้ stock/emoji รูปใหม่รวมใน JSON backup กู้คืนไฟล์เก่าได้ ตรวจโครงสร้างก่อนกู้คืนและไม่ทับข้อมูลเมื่อไม่ถูกต้อง ถ้าอ่านข้อมูลเดิมไม่ได้หยุดแอปและให้ดาวน์โหลดข้อมูลดิบ ไม่สร้างร้านว่างเขียนทับ

บันทึกโดยเขียนสำเนาสถานะให้สำเร็จก่อนเปลี่ยนสถานะในแอป เมื่อพื้นที่เต็มไม่สร้างเมนู/บิลหลอกในหน่วยความจำ

## ข้อจำกัด

“แอดมิน” ในรุ่นนี้หมายถึงคนที่เปิดหน้าจัดการร้าน ไม่ใช่บัญชีที่ยืนยันตัวตน ข้อมูลยังอยู่เฉพาะเครื่อง ไม่อัปโหลดรูปไปเซิร์ฟเวอร์ ไม่มีซิงก์กลางหรือกำไรจากต้นทุนจริง การปรับนี้เป็นงานเวอร์ชันทดลอง ยังต้องทดสอบ QR และเครื่องพิมพ์กับอุปกรณ์ร้านจริง

## ผลตรวจสอบก่อน merge

- `npm ci` ติดตั้งตาม lockfile สำเร็จ
- `npm test`: ผ่าน 15 ข้อ ครอบคลุมยอดเงิน ภาษี ส่วนลด การปันส่วนระดับสตางค์ ช่วงเปรียบเทียบ เวลาไทย บิลยกเลิก การย้ายข้อมูลและ backup
- Browser Chromium: ผ่าน 4 ชุด ครอบคลุมเพิ่มรูป/หมวด/เมนู รับเงินสด/โอน CSV โลโก้ กู้คืน ซ่อนเมนู ข้อมูลเดิมและพื้นที่เต็ม
- หน้าขาย เมนู รายงาน และตั้งค่าร้านไม่ล้นที่ความกว้าง 1024/768/390 px
- ทดสอบ static hosting ใต้ `/forTestChatGPT/` โหลดครบทุก module และขายได้
- ตรวจภาพหน้ารายงานและตั้งค่าบนแท็บเล็ตแล้ว
- ตรวจ syntax และ `git diff --check` ผ่าน

ทั้งหมดเป็นผลในเครื่องพัฒนา ยังไม่ใช่การยืนยัน GitHub Actions หรือ GitHub Pages deployment หลัง push และยังไม่ได้ทดสอบเครื่องพิมพ์/QR ธนาคารกับอุปกรณ์ร้านจริง
