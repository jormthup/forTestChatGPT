# แนวคิดรายงานและตั้งค่าร้าน

รอบ v0.2.0 พยายามอ่านเอกสารทางการของ Square และ Loyverse แต่เครือข่ายเครื่องพัฒนาปฏิเสธ HTTP CONNECT ด้วย 403 จึงไม่ได้ยืนยันเนื้อหาล่าสุดหรือคัดลอกหน้าจอ ไม่อ้างว่าผ่านการสำรวจผลิตภัณฑ์สดครบแล้ว ไม่มีการเปลี่ยน network allowlist ของผู้ใช้เพื่อขยายสิทธิ์

แหล่งสำหรับตรวจต่อเมื่อเข้าถึงได้:

- [Square Support](https://squareup.com/help/us/en): รายงานยอดขายและการตั้งค่าธุรกิจ/ใบเสร็จ
- [Loyverse Help](https://help.loyverse.com/): sales summary, sales by item/category และ receipt settings

แนวทางที่เลือกจากรูปแบบงาน POS ทั่วไปและความต้องการร้านนี้:

| ความต้องการ | การออกแบบในรุ่นนี้ | เหตุผล |
| --- | --- | --- |
| รู้ว่ายอดดีขึ้นหรือไม่ | ช่วงวันที่และเทียบช่วงก่อนที่ยาวเท่ากัน | อ่านผลได้โดยไม่เทียบคนละจำนวนวัน |
| ปิดยอดร้าน | แยก gross/discount/net/tax/collected และช่องทางรับเงิน | ตรวจยอดกับเงินสดและธนาคาร |
| เตรียมของ/คน | จำนวนขายรายเมนูและบิลรายชั่วโมง | รู้สินค้ายอดนิยมและช่วงลูกค้าเยอะ |
| ใช้ข้อมูลต่อ | CSV พร้อมวัน ชื่อคอลัมน์ และนิยามยอด | เปิดใน Excel/Sheets |
| ร้านมีเอกลักษณ์ | โลโก้ ข้อมูลติดต่อ และข้อความท้ายใบเสร็จ | ให้พนักงานตั้งเองโดยไม่แก้โค้ด |
| ป้องกันรูปเต็มพื้นที่ | ย่อรูปก่อนเก็บ แจ้งความล้มเหลว และ JSON backup | เหมาะกับข้อจำกัด browser storage |

ส่วนที่ตั้งใจไม่ใส่: กำไรสุทธิเมื่อไม่มีข้อมูลต้นทุน การยืนยันธนาคารเมื่อไม่มี integration และสิทธิ์แอดมินเมื่อยังไม่มีระบบ authentication เพื่อไม่ให้หน้าจอสื่อความสามารถเกินจริง
